# Arkoura AI World Generator

这是一个面向大型 Unity 3D 游戏地图的资产驱动生成框架。核心原则是让 AI 负责规划，让确定性程序系统负责真正的地形、材质、道路、建筑与资产放置。

## 当前 v0.1 功能

- 分块世界生成，所有高度采样使用全局坐标以保证边界连续。
- 宏观、中观、微观三层地形频率，避免单层噪声造成的碎裂感。
- 规则式 Terrain Layer 权重图生成。
- ScriptableObject 资产库与大量放置约束元数据。
- 资产批量扫描与初始标签推断。
- 建筑聚落生成器。
- 基于地形代价的道路 A* 规划器。
- 世界验证器，检查地图尺寸、分块、Terrain 分辨率、资产与理论对象数量。
- 简单运行时分块流送器。
- AI 世界规划接口与可配置 HTTP 规划器，不在 Unity 项目中保存供应商密钥。
- Unity Editor 主工具窗口。

## 资产元数据

每个资源可记录：分类、标签、生物群落、占地尺寸、最小间距、缩放范围、允许坡度、允许海拔、道路距离、水体距离、聚类倾向、稀有度、朝向规则、是否阻挡导航、是否需要地基、入口偏移、最大实例密度等。

## 大地图原则

不要生成单张超大高度图。世界被拆分为固定尺寸分块，每个分块通过同一全局采样函数生成，因此地形边缘连续。逻辑数据应以 WorldSpec、种子、资产库和少量语义图保存，而不是保存整个最终世界的重复几何数据。

## AI 接入

远程 AI 服务只需要接收自然语言描述并返回 WorldSpec JSON。生产环境建议通过自己的服务端代理调用模型，Unity 客户端只访问代理地址，不保存模型供应商 API Key。
