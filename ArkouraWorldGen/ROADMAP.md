# Arkoura WorldGen 路线图

## P0 架构稳定

- 将所有生成阶段改为可重入 Generation Pass。
- 每个 Pass 输入不可变 WorldContext，输出独立数据层。
- 加入缓存哈希，使局部修改只重建受影响分块。
- 建立可版本化 WorldSpec JSON Schema。
- 建立自动化 EditMode 测试，验证相同种子产生相同结果。

## P1 地形与水文

- GPU Compute 多频率高度场。
- 热侵蚀、水蚀、河流源点和流向图。
- 海岸侵蚀、悬崖识别与悬崖网格替换。
- 河流切割、湖泊盆地和湿度传播。
- 地形洞穴与岩石悬挑改用网格层，不依赖 Terrain 高度场。

## P2 语义与生物群落

- 温度、湿度、海拔、坡向、土壤、风暴暴露度语义图。
- 生物群落规则图。
- 生态演替和蓝噪声分布。
- 边界混合，禁止硬切换。

## P3 道路和文明

- 多层道路图：主路、次路、小径。
- 道路 A* 加入坡度、河流、悬崖、桥梁成本。
- 样条化、切土填土、路肩、护坡、桥梁与隧道。
- 城镇：道路图 -> 街区 -> 地块 -> 建筑 -> 院落 -> 道具。
- 建筑入口自动朝路，自动修正地基。

## P4 AAA 运行时

- Addressables 世界分区。
- GPU Resident / GPU Instancing 植被与道具。
- HLOD、远景代理、地形环形 LOD。
- 分块 NavMesh 和异步加载。
- 世界状态与生成状态分离，支持存档。
- 主线程预算和分帧生成。

## P5 AI Director

- 自然语言 -> WorldSpec。
- WorldSpec -> 约束图。
- 生成后视觉/结构分析。
- 发现冲突后只生成修复指令，不重新生成整个世界。
- 版本化修复操作：移动、替换、删除、道路重算、地形局部平滑、地基修正。

## P6 工具集

- 资产库表格、过滤、批量标签、批量约束编辑。
- 2D 语义地图画布。
- 3D 区域刷。
- 道路编辑器。
- 河流编辑器。
- 聚落编辑器。
- 分块性能热力图。
- 对象密度热力图。
- 生成差异查看器。
- 种子浏览器。
